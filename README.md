# Lumen
Lumen is an extension for Chromium-based browsers. This extension modifies your browser's start page to make it look better.

## Features
- Clock, personalized greeting, themes (light / dark / deep blue) and favorite sites
- Search engines with full names: Google, Bing, DuckDuckGo, Brave
- `/yt word` — search `word` on YouTube
- `gapps app-name` — open a Google app directly, without any slash (21 built-in apps, including Gemini), e.g. `gapps gmail`, `gapps gemini`, `gapps drive`
- `gapps --list` — show the list of all available Google apps
- `!bang query` — 11.000+ bangs (14.000+ triggers) from the [Kagi bang directory](https://github.com/kagisearch/bangs) — the same source used by Helium — resolved locally with suggestions while you type: `!gh arena`, `!w lumen`, `!yt music`
