# Lumen
Lumen is an extension for Chromium-based browsers. This extension modifies your browser's start page to make it look better.

## Features
- Clock, personalized greeting, themes (light / dark / deep blue) and favorite sites
- Search engines with full names: Google, Bing, DuckDuckGo, Brave
- `/yt word` — search `word` on YouTube
- `gapps app-name` — open a Google app directly, without any slash (20 built-in apps), e.g. `gapps gmail`, `gapps drive`, `gapps maps`
